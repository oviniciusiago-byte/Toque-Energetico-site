### `lib/motion.ts` — um carregador só

Todo GSAP entra por aqui (memoizado, uma vez). Exporta curvas e durações
nomeadas em vez de números soltos:

```ts
export const dur = { curta: 0.45, media: 0.85, longa: 1.25 } as const;

  entrada: '0.5, 0, 0.75, 0',
  assenta: '0.75, 0, 0.25, 1',

};
```

Isso resolve a dor de "o GSAP entra por import dinâmico, não dá para sondar do
console". Use isso para depurar em vez de adivinhar.

## 3. Design system

### Superfícies

Seções declaram `surface="paper | ink | smoke | …"` e isso define fundo, texto,
linha e acento de uma vez. A casa é quase monocromática de propósito — papel e
tinta — para não competir com a cor dos produtos nem com as fotos.

### Contraste é token, não gosto — `lib/contraste.ts`

O contraste WCAG AA é **calculado na hora de renderizar**, não escolhido a olho.

```ts
const ALVO_FORTE = 6.2;  const ALVO_MEDIO = 5.2;  const ALVO_SUAVE = 4.7;
export function rampaLegivel(cor: string): Rampa  // { campo, forte, medio, suave }
```

A "tinta" é **o próprio matiz do rótulo empurrado até quase-preto ou
quase-branco** — nunca preto ou branco puro. Onde o fundo era meio-tom sem
espaço tonal, o campo foi aprofundado de 4 % a 25 %.

> **Regra dura:** hierarquia de texto se faz **por cor**, nunca por
> `opacity-*`. 23 de 48 camadas de texto reprovaram em AA justamente porque
> utilitários de opacidade desfaziam a garantia calculada.

### Tipografia

Serifada de display + sans para corpo e rótulos; `tnum` nos números.

## 4. Decisões aprovadas

**Arquitetura de cena — `position: sticky`, nunca `pin`.**
As duas referências fazem assim. `pin` do ScrollTrigger cria um `pin-spacer`,
briga com o React na troca de rota (quebrou a página de catálogo inteira,
commit `b892f41`) e entra em laço com `ResizeObserver`.

**Altura antes da medida.** Alturas de cena são escritas no `refreshInit` do
ScrollTrigger, nunca depois — senão o refresh mede o layout errado.

**`lenis.resize()` depois de qualquer mudança de altura por JS.** O Lenis
guarda o limite de scroll em cache; sem isso a página para de rolar no meio
(travou em 9365 de 22584 px).

**Sistema de três verbos para texto** (`components/Texto.tsx`): `inicial`,
`revela`, `esconde`. Blur-in-up com SplitText, e **desfaz ao subir o scroll**.
`autoSplit: true` cuida de re-split em carga de fonte e resize.

```ts
const desfoque = { char: 10, palavra: 9, linha: 8 };
titulo: { unidade: 'char',    distancia: 22, duracao: dur.longa, passo: 0.022 }
texto:  { unidade: 'palavra', distancia: 16, duracao: dur.media, passo: 0.018 }
rotulo: { unidade: 'char',    distancia: 12, duracao: dur.curta, passo: 0.014 }
```

**Cena dos banhos = lâminas, não rolagem contínua.** `RITMO = 0.62`
(5300 px → 3551 px), `INICIO_TROCA = 0.58` — a lâmina segura 58 % do trecho e
troca rápido. Zero estado React durante o scroll.

**Foto sangrando de borda a borda**, com recorte por **orientação** da tela
(não por largura): retrato usa `top-[44%]`, paisagem usa `inset-0`.
O produto fica do **lado direito** para o texto não cobrir.

**Imagens geradas com Nano Banana Pro** (`imagen-nano-banana-2` no Magnific),
a partir das fotos reais da cliente, **uma geração por prompt** — crédito é
caro. Produtos em **4:5**, cenas dos banhos em **16:9**.

### Lições de prompt de imagem (custaram várias rodadas)

- Descrever **como a luz se comporta nas superfícies** produz queda de luz
  irregular e real. Descrever **a aparência** da luz ("gradiente", "halo") faz
  o modelo desenhar um disco geométrico.
- Mas **nomear equipamento** ("softbox", "rebatedor", "bandeira") faz o modelo
  **renderizar o equipamento dentro do quadro**.
- O prompt precisa das duas coisas: a física da luz, e o set explicitamente
  proibido.
- **"Escuro" não é "spa".** Trocar spa por dark produziu um porão de pedra —
  o Vinicius: *"Tá parecendo mais um ngc de macumba que um spa"*. O alvo é
  **"luxo e paz e natureza ao mesmo tempo"**.

## 5. Decisões descartadas

| Descartado | Por quê |
| --- | --- |
| `ScrollTrigger` com `pin` | `pin-spacer` + React = `NotFoundError: removeChild` |
| `ResizeObserver` + `refresh()` | Laço: o refresh muda o layout que o observer observa |
| `transition` CSS em valor de scroll | Congela no meio do percurso |
| Máscara com `overflow: clip` no texto | Corta o halo do blur |
| `opacity-*` para hierarquia de texto | Desfaz o contraste calculado |
| Capítulos "Sombra / Presença / Luz" | A cliente pediu atmosfera, não conceito legendado |
| Caixas tracejadas de "conteúdo em breve" | Pior que não ter a seção |
| Moldura em volta da foto do banho | A foto virou a base da própria lâmina |
| **`clip-path: ellipse` que achata (`CenaEmergente`)** | **Mecanismo errado — ver seção 7** |

## 7. A cúpula da era — o que eu errei e o que é de verdade

**Medido em `referencias/era-residence.md`. Leia esse arquivo antes de tocar no
componente.** Resumo:

| Eu implementei | A era faz |
| --- | --- |
| Elipse que **achata** | Círculo de **raio constante** (950,8 ± 1,2 px) |
| Raio **cresce** de 88 % a 300 % | Raio **nunca muda** — é `50vw` |
| Fundo **rolando** por trás | Fundo **parado** (deslocamento 0 px em toda amostra) |
| `gsap.fromTo` + `scrub` em `clip-path` | **Nenhum JavaScript** |

A receita real são sete linhas de CSS:

```css
.segura { position: sticky; top: 0; height: 100vh; }
.emerge {
  position: relative; z-index: 1;      /* obrigatório: sticky pinta acima de estático */
  background: <cor opaca>;
  border-start-start-radius: 50vw 50vw;
  border-start-end-radius:   50vw 50vw;
}
```

Os dois raios somam a largura do elemento → os quartos de círculo se encontram
no centro → semicircunferência perfeita de `50vw`. O conteúdo de dentro sobe
junto porque **é a seção inteira que rola**, 1:1 com o scroll, por `100vh`.

**A lição maior:** eu vinha tratando "animação de nível awwwards" como sinônimo
de ScrollTrigger. O momento mais bonito da página inteira da era **não tem uma
linha de JS**. Eles usam GSAP onde precisa e CSS puro onde não precisa.
